# Ankara Apple Store

Landing page estática en español para Ankara Apple Store. Abrí `index.html` en un navegador o publicá la carpeta completa en un hosting estático.

## Personalización rápida

- Los enlaces a WhatsApp usan el número internacional indicado por el negocio: `543775409164`.
- Los datos, categorías, mensajes y enlaces sociales se editan en `index.html`.
- La tipografía usa Poppins y Contrail One desde Google Fonts; hace falta conexión a internet para descargarlas.
- Las fotografías de productos están en `assets/products/`. Reemplazá esos archivos conservando sus nombres para cambiar las imágenes, o actualizá las rutas y el texto alternativo en `index.html`.
- El logo compartido está en `assets/ankara-logo.png`.

No se publica la dirección del domicilio. La página solo menciona Monte Caseros, Corrientes, como zona de entrega.
